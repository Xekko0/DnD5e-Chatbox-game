# XekkoDND – Solo D&D 5e AI Chatbox

**Dự án game chatbox AI D&D cho 1 người chơi**, chạy local (Tauri app) hoặc web.

**Người tạo:** Xekko (solo dev)

## Mục tiêu
Xây dựng AI DM thông minh + Rule Engine 5e nghiêm ngặt + Layered Memory, hoàn toàn local, có image gen chất lượng cao từ model Civitai.

## Tài liệu
- [PROJECT_PLAN.md](PROJECT_PLAN.md) – Kế hoạch chi tiết, realistic cho solo dev (14-16 tuần)

## Tech Stack (dự kiến)
- Tauri + React/TS
- Python (Rule Engine + State)
- Groq / Gemini (AI DM)
- ComfyUI local (Image gen)
- SQLite

## Bắt đầu
Repo đang ở giai đoạn MVP prototype (Streamlit). Sẽ chuyển sang Tauri sau khi core ổn định.
