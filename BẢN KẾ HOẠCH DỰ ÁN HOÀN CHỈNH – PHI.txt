---

### 1. TỔNG QUAN DỰ ÁN

**Mô tả:**  
Ứng dụng chatbox AI đóng vai Dungeon Master (DM) thông minh. Người chơi chat text/voice → AI xử lý theo luật 5e → trả lời narrative + cập nhật realtime Character Sheet, Map, Inventory, Combat Tracker, Audio. Toàn bộ game state được quản lý bởi **Layered Memory** (World Lore cố định + Character Stats + Recent Events + Game Snapshot).

**Đặc điểm nổi bật:**  
- 100% single-player, offline-first (local LLM).  
- Layered Memory + Rule Engine → giảm hallucination gần như bằng 0.  
- Multi-output: Narrative + Map token + Audio cue + State delta (HP, item, position…).  
- Cả AI và người chơi đều có quyền cập nhật state (player edit sheet → AI biết ngay).  
- Tuân thủ D&D 5e SRD (không cần mua sách).  
- Hỗ trợ campaign editor, voice, image gen, combat visual.

**Phạm vi MVP:** 1 campaign đầy đủ (3-5 sessions) + World Builder cơ bản. Sau MVP mở rộng.

### 3. LUỒNG HOẠT ĐỘNG CHI TIẾT (User Flows)

**Flow 1: Khởi động**  
1. Mở app → Welcome → New Campaign / Load / Tutorial.  
2. Character Creation Wizard (full steps).  
3. Chọn/Load World Lore → Load state → Vào chat.

**Flow 2: Chat Core Loop**  
Player input → Intent Parser → Rule Engine validate → LLM narrative → Multi-output (text + map + audio + state) → UI update realtime.

**Flow 3: Combat**  
Trigger combat → Auto Initiative + Combat Tracker UI → Turn loop (player/AI) → Visual attack + damage → End combat → Loot.

**Flow 4: Player Edit State**  
Mở Character Sheet → Edit AC/HP/Item → State update → AI context tiếp theo biết ngay (không cần chat nhắc).

**Flow 5: World Builder**  
Sidebar → Map Editor → Save → Dùng trong campaign.

### 4. KIẾN TRÚC KỸ THUẬT (Chi tiết)

**Tech Stack (Local-first, solo-dev):**  
- **App**: Tauri (Rust backend + React/Next.js 15 frontend + TypeScript + Tailwind + shadcn/ui).  
- **State**: Zustand + JSON + SQLite (Lore DB) + ChromaDB (history vector).  
- **Rule Engine**: Pure TypeScript module.  
- **AI**: Ollama (llama3.1:8b/14b) + custom prompt. Toggle Grok API.  
- **Map**: React-Konva + grid system.  
- **Audio**: Howler.js + Web Audio API.  
- **Voice**: Whisper.cpp local + Web Speech API.  
- **Image**: Grok Imagine API local fallback.  
- **Data**: SRD 5e JSON import.

**Monorepo Structure (đầy đủ):**  
```
/xekkodnd
├── src/
│   ├── core/          (StateManager, LayeredMemory, RuleEngine, MultiOutputPipeline)
│   ├── ui/            (Chat, CharacterSheet, CombatTracker, MapEditor, InventoryGrid…)
│   ├── ai/            (Prompts, IntentParser, CampaignEngine)
│   ├── data/          (srd-json, monsters, spells, items, campaigns)
│   ├── utils/         (Dice, Audio, Validation)
│   └── types/         (TypeScript interfaces cho mọi state)
├── tauri/             (desktop build)
├── public/            (assets, sounds, images)
└── docs/              (prompts, rules, this plan)
```
